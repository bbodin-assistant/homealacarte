Sauvegarde en ligne

Compte du foyer

Un compte partagé synchronise les données du foyer entre vos appareils. La copie locale reste disponible en cas de panne.

La copie en ligne est vérifiée au démarrage, à la connexion et lors d’une synchronisation manuelle. Il n’y a pas de vérification périodique en arrière-plan.

Comprendre tous les statuts
En ligne + hors ligne
Les données sont enregistrées en ligne dans Supabase et hors ligne sur cet appareil.
Envoi en ligne…
Les modifications sont déjà enregistrées hors ligne sur cet appareil et sont en cours d’envoi vers Supabase.
Connexion en ligne…
La copie hors ligne est disponible sur cet appareil. Connexion à la copie en ligne en cours.
Hors ligne uniquement — compte déconnecté
Les données sont enregistrées hors ligne sur cet appareil uniquement. Connectez-vous pour les sauvegarder aussi en ligne.
Hors ligne uniquement — sauvegarde non configurée
Les données sont enregistrées hors ligne sur cet appareil uniquement. Aucune copie en ligne n’est configurée.
Hors ligne uniquement — serveur inaccessible
Les données sont enregistrées hors ligne sur cet appareil. Supabase est actuellement inaccessible ; la copie en ligne sera actualisée au retour de la connexion.
Conflit à résoudre
Les copies en ligne et hors ligne sont différentes. Les données hors ligne restent disponibles pendant que vous choisissez la version à conserver.
Erreur de synchronisation
Les données restent enregistrées hors ligne sur cet appareil, mais la sauvegarde en ligne a rencontré une erreur.

Connecté en tant que

Les données locales et en ligne ont changé. Choisissez la version à conserver.

    Le projet

    À propos de Home à la Carte

    Un planificateur local-first et open source pour organiser le foyer, les menus, le stock et les courses.

    Technologie et partage

    L’application est un site statique sans Node ni serveur applicatif : HTML, CSS et JavaScript pour l’interface, Rust/WebAssembly pour les calculs et le PDF, IndexedDB pour la copie locale, et Supabase en option pour la synchronisation.

    Le code est partagé sous licence MIT : chacun peut l’utiliser, le modifier et l’héberger, en conservant la notice de licence.

    Voir le code source et contribuer sur GitHub

    Données personnelles et RGPD

    Responsable du traitement de cette instance : Non renseigné. L’adresse e-mail sert uniquement à créer le compte et à synchroniser les données choisies par l’utilisateur.

    Finalité : fournir l’organisation du foyer, des repas, des besoins, du stock et des courses. Les données peuvent inclure l’adresse e-mail, les noms ou pseudonymes, les habitudes alimentaires, les objectifs nutritionnels, les menus, le stock et les achats saisis. La base légale du compte est l’exécution du service demandé ; un consentement explicite est demandé pour les informations pouvant révéler la santé. Le titulaire confirme avoir informé les autres personnes et obtenu les autorisations nécessaires.

    Une copie nécessaire au fonctionnement hors ligne est conservée dans IndexedDB sur l’appareil. Avec un compte, le document et les éventuelles demandes privées sont aussi envoyés au projet Supabase hébergé dans la région Europe. Des sous-traitants Supabase peuvent traiter des données hors EEE selon son DPA et ses clauses contractuelles types. Il n’y a ni publicité, ni analyse d’audience, ni vente de données.

    Un compte contenant des données est destiné à être supprimé après un an sans activité ; un compte vide après une semaine. Sur le plan gratuit, cette purge d’inactivité reprend lorsque le projet est actif car Supabase peut le mettre en pause. Supprimer mes données efface immédiatement le document, les demandes privées, le compte en ligne et la copie de cet appareil. L’exploitant ne crée aucune sauvegarde ; les copies ou journaux techniques éventuels du fournisseur suivent ses propres conditions.

    Mes données permet l’accès et la portabilité par téléchargement JSON, la rectification dans les écrans, l’effacement immédiat et l’envoi d’une demande privée au responsable. Une réponse est normalement fournie sous un mois. Une réclamation peut être adressée à la CNIL. Aucun profilage commercial ni décision produisant un effet juridique n’est réalisé.
